# Statistik Indonesia — make.fun bounty entry

Static national statistics site for Indonesia (BPS/World Bank figures 2015–2024): hash-routed pages (Ringkasan, Populasi, Ekonomi, Pendidikan, Kesehatan, Geografi, Bandingkan), inline SVG charts, interactive year selectors and a compare-years view. Vanilla JS, no build step, no network requests.
