# Statistik Indonesia — make.fun entry

Static national statistics site for Indonesia (BPS/World Bank data, 2015–2024), vanilla JS + inline SVG charts.

![status](https://img.shields.io/badge/status-submitted-brightgreen) ![license](https://img.shields.io/badge/license-MIT-blue) ![makefun](https://img.shields.io/badge/make.fun-bentry-orange)

- No build step, no network requests, all data embedded.
- Pages: Ringkasan, Populasi, Ekonomi, Pendidikan, Kesehatan, Geografi, Bandingkan (year-compare).
